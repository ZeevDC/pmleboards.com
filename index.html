☁️ Cloud Sync Setup (Cloudflare Worker)

Paste your Cloudflare Worker URL below. The Worker keeps your GitHub token secure — it never touches the browser.

  1. Deploy cloudflare-worker.js to workers.cloudflare.com
  2. In the Worker Settings → Variables, add GITHUB_TOKEN (encrypted) and GIST_ID
  3. Copy the Worker URL (e.g. https://pmle-proxy.YOUR-NAME.workers.dev)
  4. Paste it below and click Save
